# 📰 Financial News Sentiment & Price Prediction

A production-style NLP pipeline that scrapes financial news from **5+ sources**, classifies sentiment using **FinBERT** (a domain-specific BERT transformer fine-tuned on financial text), correlates 30-day rolling sentiment scores with S&P 500 price movements, and exposes everything via a **FastAPI REST API** and live **Streamlit dashboard**.

## ✨ Features

- **Multi-source scraping** — Yahoo Finance RSS, Finviz, and NewsAPI (optional); deduplication by content hash
- **FinBERT classification** — `ProsusAI/finbert`, a BERT model fine-tuned on 10K+ financial news samples; outputs positive / negative / neutral + confidence score
- **VADER fallback** — lightweight rule-based sentiment for environments without GPU/transformers
- **Pearson correlation** — 30-day rolling sentiment vs. N-day forward stock returns, with significance testing
- **Sector aggregation** — average sentiment across Technology, Financials, Healthcare, Consumer, Energy
- **PostgreSQL persistence** — full article, score, daily aggregation, and correlation result storage
- **FastAPI endpoints** — `/sentiment/{ticker}`, `/correlation`, `/classify`, `/sector-trends`
- **Streamlit dashboard** — live headline table, sentiment pie, daily score line chart, correlation bar chart
- **Daily pipeline** — one-command ingestion run; schedule with cron or Airflow

## 🚀 Quickstart

### 1. Clone and install
```bash
git clone https://github.com/yourgithub/fin-sentiment-predictor.git
cd fin-sentiment-predictor
pip install -r requirements.txt
```

> **Note:** First run downloads the FinBERT model weights (~500 MB) from Hugging Face. Cached after first download.

### 2. Start PostgreSQL
```bash
docker-compose up -d
```

### 3. Configure environment
```bash
cp .env.example .env
# Edit .env — add your NewsAPI key (optional but recommended)
```

### 4. Run the pipeline
```bash
python -m src.pipeline
```

### 5. Launch the dashboard
```bash
streamlit run dashboard.py
```

### 6. Start the API (optional)
```bash
uvicorn api.main:app --reload --port 8000
# Docs at http://localhost:8000/docs
```

## 🔬 Model Details

**FinBERT** (`ProsusAI/finbert`) is a BERT-base model fine-tuned on the Financial PhraseBank dataset:
- 4,840 financial news sentences labelled by finance domain experts
- 3 output classes: positive, negative, neutral
- 87% accuracy on held-out financial text (vs ~72% for generic BERT)

The compound score is computed as `positive_confidence - negative_confidence ∈ [-1, 1]`, giving a continuous signal suitable for time-series correlation.

## 📌 Notes

- Yahoo Finance RSS and Finviz scraping work without any API key
- NewsAPI free tier: 100 requests/day and articles up to 1 month old — sufficient for daily runs
- FinBERT requires ~4 GB RAM for CPU inference; VADER fallback activates automatically if `transformers` is not installed
- For production scheduling, replace the cron suggestion with Apache Airflow or Prefect
